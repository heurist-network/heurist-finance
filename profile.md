# Profile

Read this before any analysis or plan. Update it when the user tells you something new about themselves; append to Lessons only from a post-mortem.

This file is context, not a mandate: it tells you the user's constraints and tendencies so the analysis fits their situation. It does not tell you the answer. The user is open to new ideas and does not want to be steered back to a past thesis or position (see Personalization in `AGENTS.md`).

## Who
- Where you are based and what tax applies to your gains (or "tax is not a factor").
- Experience: years investing, asset classes, whether you have used leverage or options.
- Background that shapes what analysis you can use (statistics, code, an industry you know well).
- Brokers, and how fills reach this repo (receipt screenshots, CSV exports, typed by hand).
- Information diet: which sources you trust, and which you want fact-checked with `thesis-audit` first.

## Portfolio stance
- Size of the book and how much is in cash. Holdings live in `trading/portfolio.md`.
- Mandate, if any (a required cash/bond/stock mix), or "none".
- Risk tolerance in plain words, and what never to pitch.
- Deliberate choices the agent should not relitigate (for example, a concentration you chose on purpose).
- Themes you follow; the daily brief uses them to pick stories.
- Working theses, each dated, stated as hypotheses under test.

## How the user trades, and where it goes wrong
- Entry style: scaling in on dips, buying breakouts, single entries.
- Known failure modes: exiting on fear mid-trade, drifting from the written plan, chasing, being too timid to follow strength.
